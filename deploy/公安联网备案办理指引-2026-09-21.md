## 1. 去哪办

**全国互联网安全管理服务平台**：<https://beian.mps.gov.cn/>

进程是「**注册 → 实名 → 开办主体 → 网站备案 → 公安备案号**」，与 ICP 备案是**两套系统**，
ICP 已通过**不**代表公安这边自动完成（腾讯云只是把信息同步给了公安部，仍需你本人去认领）。

手机端也有官方 App（应用商店搜「备案」/ 全国互联网安全管理服务平台），第 2~4 步在 App 上做更顺。

## 3. 办完之后：悬挂公安备案号（一处改动即生效）

拿到编号后，改 `deploy/site/index.html` 底部**已经预置好的那段注释**：

```html
<!-- 把这两行的注释去掉，并把 XXXXXX 换成你的公安备案号 -->
<span class="sep">|</span>
<a class="beian" href="https://beian.mps.gov.cn/" target="_blank" rel="noopener noreferrer">冀公网安备 XXXXXXXXXXXXXX 号</a>
```

要点：
- **链接指向** `https://beian.mps.gov.cn/`（或该平台的查询页）；公安备案号**必须与 ICP 备案号并列悬挂**，
  不能只挂一个。
- **官方图标**：在 beian.mps.gov.cn 的「备案图标下载」处下载，放到
  `/var/www/dashuai-web/assets/beian.png`，然后把那段注释里的 `<img>` 一并启用
  （图标不是硬要求，但带图标更接近标准样式）。
- 改完只需重传首页文件，**不用重启任何服务**：

```bash
scp deploy/site/index.html ubuntu@49.232.243.241:/tmp/web-index.html
ssh ubuntu@49.232.243.241 'sudo cp /tmp/web-index.html /var/www/dashuai-web/index.html'
```

**判据**（一条命令自证）：

```bash
curl -s https://dspcz.top/ | grep -o '冀公网安备[^<]*'   # 有输出 = 已悬挂
curl -s https://dspcz.top/ | grep -o '冀ICP备[0-9]*号-[0-9]*'  # 现在已有输出：冀ICP备2023045927号-2
```
