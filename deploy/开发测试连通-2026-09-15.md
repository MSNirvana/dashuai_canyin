## 2. 原理：为什么用 IP 能绕过备案

腾讯云接入层按 **Host 头** 拦截「本厂商侧无有效备案记录」的域名：

| 请求 | 结果 |
|---|---|
| `Host: api.dspcz.top`（HTTP） | ❌ 302 到 `webblock`，20/20 次全拦 |
| `Host: api.dspcz.top`（HTTPS） | ❌ 按 SNI 直接 RST |
| **`Host: <IP>`（HTTP，直连 80）** | ✅ **请求正常到达本机 nginx** |

**判定依据**：外网 `curl -H 'Host: 49.232.243.241' http://49.232.243.241/` 拿到的是
**本机 nginx 生成的 170 字节错误页**，与在服务器上 `curl 127.0.0.1` 的结果**逐字节一致**。
说明请求没被云端拦掉，只是被 nginx 处理错了。

**而被处理错的原因**是：`dashuai-admin.conf` 因文件名字典序在前，成了 80 端口的
**隐式 default server**；它的 `root /opt/dashuai/apps/admin/dist` 尚未构建，
`try_files` 找不到文件 → 一律 **500**。

⇒ 于是加了显式 `default_server` 把「非域名 Host」的请求转交给 API 进程。
配置文件：`deploy/nginx/dashuai-dev-ip.conf`
服务器位置：`/etc/nginx/conf.d/00-dashuai-dev-ip.conf`

> 注：之前文档里说的「直连 IP + Host 头也被拦」不够精确 —— 被拦的是
> **Host 为备案域名**的那种「直连 IP + Host 头」。Host 换成 IP 本身并不被拦。

## 3. 你要做的（3 步）

### ① 微信开发者工具勾选「不校验合法域名」

`详情 → 本地设置 → 勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」`

不勾的话，`http://` 与 IP 地址会被微信直接拦掉，报「不在以下 request 合法域名列表中」。

### ② 重新编译小程序

`apps/mini/.env` **已经改好**了：

```
TARO_APP_API_BASE_URL=http://49.232.243.241/api/v1
```

该值会作为 `__API_BASE_URL__` **编译期注入**，所以改完必须重新编译：

```bash
cd apps/mini && npm run dev:weapp
# 或用微信开发者工具打开 dist 目录后点「编译」
```

> 想切回本地联调：编辑 `apps/mini/.env`，注释掉服务器那行、启用
> `http://127.0.0.1:3000/api/v1` 那行，再重新编译。

### ③ 真机测试时打开调试开关

模拟器不用管。**真机**必须打开「调试」才会跳过域名校验：

- 用工具栏「**真机调试**」扫码（最简单，自动带上）
- 或用「预览」扫码后：手机小程序右上角 `···` → **开发调试** → 打开调试

## 4. ⚠️ 唯一可能卡住的地方：手机号快速验证

服务端的登录入口只剩一条路（实测确认）：

| 登录方式 | 状态 |
|---|---|
| `POST /auth/wechat-login`（`getPhoneNumber`） | ✅ **唯一可用**，需小程序后台开通「手机号快速验证」 |
| `POST /auth/login`（手机号 + 短信验证码） | ❌ `SMS_PROVIDER` 为空 → 503 |
| `POST /auth/dev-login` | ❌ `DEV_LOGIN=false`，且生产环境守卫会拒绝启动 |

所以 **`wx.getPhoneNumber` 能不能拿到 `phoneCode`** 是登录的前提。

**请确认「手机号快速验证」是否已开通**（微信公众平台 → 功能 → 手机号快速验证）。
没开通的话点登录按钮不会有反应 —— 届时在开发者工具里一试便知。

> 备选方案（如果没开通）：临时把 `NODE_ENV` 改成 `staging` 并开 `DEV_LOGIN=true` 走手机号
> 直登。但这会让生产的八个 fail-closed 守卫全部失效，**只在本地临时用，测完必须改回**。

## 5. 当前受限的功能（与本次连通无关，本来就缺配置）

| 功能 | 状态 | 原因 |
|---|---|---|
| 微信支付 | ⛔ 关闭 | `PAYMENTS_ENABLED=false`，且 `notify_url` 必须 HTTPS 域名 → **等备案** |
| AI 文案/分镜 | ⛔ 不可用 | `DEEPSEEK_API_KEY` 为空；且 seed 把供应商写成了 `enabled=false` |
| 短信登录 | ⛔ 不可用 | `SMS_PROVIDER` 为空 |
| 视频合成 | ⚠️ 可跑但慢 | `FFMPEG_WORKER=true`，服务器本地跑 ffmpeg 8.0.1 |
| COS 上传 / 图片显示 | ✅ 正常 | COS 域名不受备案影响（`dashuai-1485028436.cos.ap-beijing.myqcloud.com`） |

**正式版小程序仍然必须用备案 HTTPS 域名**，IP 直连只能用于开发版 / 体验版。
这是微信的硬规则，与备案无关。
