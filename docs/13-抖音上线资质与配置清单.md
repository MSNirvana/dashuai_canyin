## 2. 备案类：三件不同的事，别混为一谈

很多人把这三件当成一件，结果卡在最后一步。它们的**办理机关、周期、材料完全不同**：

| | 小程序备案 | ICP 经营许可证 | 算法备案 |
|---|---|---|---|
| 机关 | 省通信管理局（平台代收） | 省通信管理局 | 国家网信办 |
| 性质 | 行政备案（准入） | **行政许可**（经营） | 行政备案 |
| 周期 | 管局 3~7 工作日 | **40~90 工作日** | 以周~月计 |
| 免费 | 免费 | 官方免费 | 免费 |

### 2.1 小程序备案（工信部要求，抖音侧单独一套）

★★ **这是在抖音侧单独办的，与微信端那套不通用**——同一主体在两个平台要各办一次。

**入口** [官]：抖音开放平台 **控制台 → 进入小程序后台 → 基础设置 → 备案信息 → 点击「去备案」**

**材料清单** [官]：

| 材料 | 提供方式 |
|---|---|
| 主体证件（营业执照） | 开发者准备 |
| 小程序负责人证件 | 开发者准备 |
| 前置审批 / 专项审批文件 | 开发者准备（命中才需要） |
| 小程序负责人核验现场拍摄照片 | **在平台操作备案时现场完成** |
| 互联网信息服务承诺书 | 在平台操作时**阅读确认** |
| 小程序备案真实性核验单 | **平台提供** |
| 补充材料（授权书/情况说明/承诺书） | 按规则提供 |

- [ ] ★★ **AI 相关小程序（名称/简介/经营内容涉及 AI）在备案阶段就要提交算法备案材料** [官]
      —— 注意「备案」这一步就要，不必等到类目资质那一步。要求见 §2.3。
- [ ] 命中前置审批关键词但不实际经营 ⇒ 上传《不涉及前置审批承诺书》
- [ ] ★ **省份特殊规则** [官]，做之前查一遍你主体所在省的《备案特殊省份规则》：
      - **广东**：备案材料里「备案」表述需改成「**核准**」；不支持电子版营业执照（要原件扫描/彩色拍照件）
      - **湖南 / 广东**：主体负责人**必须为法人**（个体工商户也必须）
      - **广东**：服务内容涉及「网络社交」「即时通讯」才要《增值电信业务经营许可证》
- [ ] ★ 已上线小程序 **每年 3 月 31 日前更新备案**，逾期下架/停更 → 排进年度日历
- [ ] 域名可复用现状：`api.dspcz.top` 已 HTTPS（LE，2026-12-20 到期），满足「必须 HTTPS、禁 IP/localhost/泛域名」

### 2.2 ★★ ICP 经营许可证（增值电信业务经营许可证 · B25）—— 需要你判定

**这是我上次清单里漏掉的一条，而且周期最长。**

- **触发条件** [三方，多源一致]：**会员订阅、付费内容、充值、广告变现**等有偿信息服务 ⇒ 属「经营性互联网信息服务」⇒ 需办 ICP 许可证。
- **本项目命中情况**：我们有 **¥980 会员订阅** + **积分加油包充值** ⇒ 按这个口径**大概率需要**。
- **平台侧口径** [官]：添加服务类目时，「服务资质」处要求上传 ——
  **《非经营性互联网信息服务备案核准》 _或_ 《增值电信业务经营许可证》（二选一）**
  ⇒ 说明**平台审核这一关**可能接受非经营性备案核准。
- **法规侧**：备案只允许你「存在」，不允许你「经营」。有付费行为而只有备案，属实质违规（可被关停、没收违法所得、罚款 3~5 倍）。
- **门槛** [三方，多源一致]：注册资本 **≥100 万**（认缴即可，但章程要写明）、**3 人社保**、纯内资、技术方案/业务发展报告等。
- **★ 建议动作（别等）**：
  1. 先按平台口径走（提交非经营性备案核准），保证不被流程卡住；
  2. **同时**去省通信管理局官网查 B25 受理要求，核对注册资本与社保能否满足；
  3. 若满足 → **现在就排期办**（40~90 工作日，是整条链上最长项）；
  4. 若不满足（如注册资本不够）→ 这是一个**产品级决策点**：要么增资，要么调整收费形态（例如把收款放到小程序之外）。**这条会直接决定抖音端能不能在线收款。**

### 2.3 ★★ 算法备案（生成合成类 / 深度合成）

**入口** [官]：**互联网信息服务算法备案系统 `https://beian.cac.gov.cn`**

**填报结构**（三大块）[三方，但与官方公告一致]：
1. **主体信息**：主体基本/证件信息、法定代表人、**算法安全责任人**；
   上传《算法备案承诺书》《落实算法安全主体责任基本情况》（按模板、**加盖公章**）
2. **备案信息（算法）**：算法类型选 **「生成合成(深度合成)」**，角色选 **服务提供者** 或 **服务技术支持者**；
   上传《算法安全自评估报告》《拟公示内容》
3. **产品及功能信息**：产品名称、服务形式、访问地址、服务状态、服务对象、是否实名/前置许可、功能访问路径

- [ ] ★★ **时限**：**首次算法备案应在「提供服务之日起 10 个工作日内」办理**；变更 10 日内；注销 20 日内 [三方，与《深度合成规定》一致]
      ⇒ 意味着**先上线后补备案本身就是违规**，且抖音在备案/类目两步都会卡它。
- [ ] 审查：网信部门 **30 个工作日内**，通过后在系统公示备案编号。
- [ ] ★ **APP / 网页 / 小程序**，任一形式提供算法服务**都要备案** [三方]。

**抖音平台要什么材料** [官·社区，抖音开放平台官方社区帖]：

给 AI 工具类目上传的算法备案材料是 **2 张页面截图**：
1. **备案查询结果页截图**（在 `beian.cac.gov.cn/#/index` 按「主体名称」或「备案编号」查询，**状态须为「正常」**）
2. **算法公示内容图片**（在系统里下载公示内容）

并且：
- **自研算法** ⇒ 上传自研的上述两截图
- **第三方算法服务** ⇒ 除两截图外，**还要合作协议**，协议**至少须包含 4 个要素**：
  【小程序主体】【算法及应用名称】【备案编号】【小程序 appid】
- 若第三方是**字节自家模型产品（豆包/火山等）** ⇒ 另需双方合同协议，证明合作关系（可找火山 BD 开）
- ★ 平台提供**合作协议模板**，按模板开最保险

**★★ 对本项目最关键的风险（必须解决）**：

| 路径 | 可行性 | 代价 |
|---|---|---|
| A. 用第三方已备案算法 | 需第三方出具**备案截图 + 公示内容 + 含 4 要素的合作协议** | ⚠ 我们走的是自建网关 + **tokenbox 这类中转站**，**中转站通常没有自己的算法备案**（它只是转售上游模型） |
| B. 换成已备案的模型厂商直连 | 高（豆包/火山、通义等均有备案） | 要改网关配置；★ 若用火山，还能顺带满足「字节自家模型要合同」那条 |
| C. **自己主体办一份备案** | 最稳 | 材料重、周期长，但**你是面向用户提供合成服务的那个主体**，监管口径下本就是「服务提供者」 |

★ **我的判断**：即使上游模型有备案，**「面向用户提供深度合成服务」的主体是你**，实务上最稳的是 **C（自办一份）**，
或者 **B（换成有备案的厂商直连）+ 保留合作协议**。**A 基本走不通**（中转站拿不出备案）。
⇒ **建议本周就向 tokenbox 要备案材料确认；拿不到就走 B/C，别拖**——这条决定项目在抖音端能不能成立。

## 4. 不需申请、但必须做的合规动作（漏了必被驳）

- [ ] ★★ **AIGC 显式 + 隐式标识**（《AI生成合成内容标识办法》2025-09-01 强制国标）
      - **显式**：成片画面要有用户可明显感知的「AI 生成」标识（角标/水印），**且下载导出后仍带**
      - **隐式**：成片**文件元数据**里写入生成合成属性、服务提供者名称/编码、内容编号
      - ★ 抖音审核看**展示层面能否看到**，不只是后台勾选
- [ ] ★★ **提审测试号** [官]：**存在仅特定用户可用的功能或付费内容的，必须在 IDE 上传时于【更新日志】/提审备注里填测试号（账号 + 密码）**，保证审核者能体验**全部**功能
      ⇒ 本项目注册赠积分 = 0、用 AI 须先买 ¥980 会员 ⇒ **不给审核员一个已开通会员的测试账号，点「AI 出片」会 403（码 2005），必被驳**。这是最容易踩的坑。
- [ ] ★ **[官] 必须提供抖音授权登录**：运营规范 10.6.1「小程序内存在账号体系时，必须提供抖音授权登录，且满足平台交互规范」
      ⇒ **推翻了「抖音首版只用短信验证码登录、把 tt.login 降级为后续增强」的想法**——有账号体系就必须有抖音授权登录。
      **但**：运营规范是**平台侧**要求，我们**不提供**「没绑定抖音就拒绝使用」（10.6.3 禁止以第三方注册为由拒绝使用），短信兜底仍可保留。
- [ ] **[官]** 必须提供功能正常且**易于发现的「退出」选项**；拒绝授权后须清除并不再使用该用户抖音头像/昵称
