Design Principles

四条设计原则

商家用户不是设计师。他们在后厨、在收银台、在等菜的间隙掏出手机。界面必须比他们的注意力更快。

01

一屏一件事

每屏只有一个主行动点（红色实心按钮）。其余操作降为文字链或浅底按钮，用颜色权重区分优先级，而不是用位置。

02

红色只给下一步

Logo 红是稀缺资源。只出现在「当前选中态」「主行动按钮」「进度与状态」三处。滥用红色等于没有重点。

03

状态永远可见

AI 在生成、视频在上传、成片在合成 —— 每一步都有明确的进度、耗时预期与失败后的重试入口，绝不让用户盯着空白猜。

04

花的是积分，先说清楚

任何消耗积分的动作，按钮旁常驻「约 XX 积分 / 可用 XXXX」。不制造账单惊喜，是这个工具能被信任的前提。

Color System

色彩系统

主色直接从 Logo 取样（实测主色约 #D02018）。考虑到小尺寸屏幕与白色背景下的观感， 将品牌红统一到 #E1251B —— 与 Logo 同色相、略提亮度，保证在按钮和图标上足够醒目且不发暗。 中性色去掉了暖调，改用近 iOS System Gray 的冷灰阶，这是「高级感」的主要来源。

Interaction & Usability

交互与可用性规范

面向「非专业用户 + 单手操作 + 店内嘈杂环境」的针对性设计约束。

场景规范
触控尺寸 所有可点击元素最小 88rpx × 88rpx（44pt）；主按钮高度 96rpx，底部操作条内的按钮 104rpx。相邻可点区域间距 ≥ 16rpx，避免误触。
拇指热区 主行动按钮一律固定在底部操作条或页面下半部；顶部只放导航与门店切换，不放高频操作。
点击反馈 按下态：实心红 → #C21B12，卡片 → scale(.98) + 透明度 0.7，时长 120ms。禁止使用系统默认的灰色遮罩。
AI 等待 生成文案 / 分镜时按钮进入 loading 并锁定，禁止重复提交；超过 8 秒追加文案「AI 正在写，通常 5–15 秒」。
上传进度 选完视频立即显示本地缩略图占位（不必等上传完成），叠加红色细进度条与百分比；失败保留卡片并提供「重新拍摄」。
消耗前置告知 任何扣积分的按钮，旁边常驻「约 XX 积分 / 可用 XXXX」；提交前用底部弹层二次确认，文案写明「按实际时长结算，失败全额返还」。
空状态 不用「暂无数据」。改为「还没有门店 → 去创建」「「XX 店」还没有创作 → 新建创作」，永远给出下一步动作。
错误与重试 失败信息用页面内联提示条（浅红底）而非 Toast；每条错误必须附带一个可点击的恢复动作（重试 / 刷新 / 去充值）。
门店上下文 门店切换器常驻首页 / 创作 / 菜品 / 人设页左上角，切换后当前页数据立即重载，避免「看到的是别家店的数据」。
动效 只用 ease-out，时长 200–260ms；仅用于页面转场、弹层升起、进度推进。不做装饰性动画。
无障碍与对比度 正文对比度 ≥ 7:1（#111114 on #FFFFFF）；次要文字 ≥ 4.5:1；红色文字只用于 ≥ 26rpx 的强调文本，小字一律用深红 #C21B12 或中性色。
