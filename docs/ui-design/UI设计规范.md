# 大帅餐饮 · 小程序 UI 设计规范 v1

> 配套高保真方案：`docs/ui-design/大帅餐饮-UI设计方案.html`（浏览器打开可看 10 个核心界面）
> 绘制基准：iPhone 15，375 × 812 pt；小程序内 **1px = 2rpx**

---

## 1. 设计定位

面向餐饮商家的短视频创作工具。用户不是设计师，操作场景是后厨、收银台、等餐间隙。

**风格关键词**：Logo 红单点强调 · 白底冷灰层次 · iOS 式留白与克制 · 零渐变零重阴影。

### 四条原则

| 原则 | 含义 |
| --- | --- |
| 一屏一件事 | 每屏只有一个红色实心主按钮，其余操作降级为浅底/文字链 |
| 红色只给下一步 | 品牌红仅用于「当前选中态」「主行动按钮」「进度与状态」三处 |
| 状态永远可见 | 生成、上传、合成全程有进度与耗时预期，失败必有重试入口 |
| 花积分先说清楚 | 所有扣费按钮旁常驻「约 XX 积分 / 可用 XXXX」 |

## 2. 顶部品牌字标

首页顶部原「创作工作台 / 功能说明 / 背景 slogan」整块收敛为唯一品牌字标：

> **餐饮门店·轻松拍**

采用楷体/手写感字体放大呈现，配合轻微旋转、红色手绘双划线和两个墨点，形成绘画式字标；不再同时展示「创作工作台」、功能说明或另一条 slogan。

| 属性 | 规格 |
| --- | --- |
| 内容 | `餐饮门店·轻松拍` |
| 字体 / 字号 / 字重 | `STKaiti`, `KaiTi`, `Kaiti SC`, serif / 76rpx / 800 |
| 颜色 | `--td-brand-color` |
| 手绘处理 | 旋转 -1.5°、红色主划线 + 淡色回笔线 + 两个墨点 |
| 层级 | 顶部操作栏保留；字标独立成块，不遮挡门店切换和个人入口 |
| 交互 | `pointer-events:none`，整块不参与点击 |

## 3. 色彩 Token

主色取自 Logo 实测主色 `#D02018`。考虑小尺寸屏幕与白底观感，统一提亮至 **`#E1251B`**（同色相、略提亮度，避免发暗）。
中性色**去掉暖调**，改用冷灰阶（对齐 iOS System Gray）——这是「高级感」的主要来源。

## 3. 字体与字阶

字体栈：`-apple-system, BlinkMacSystemFont, "SF Pro SC", "PingFang SC", "Helvetica Neue", sans-serif`
全局字距收紧 `-0.01em ~ -0.04em`（大标题收得更紧）。

| 层级 | px / 行高 | rpx | 字重 | 用途 |
| --- | --- | --- | --- | --- |
| Large Title | 38 / 45 | 76 | 800 | 首页手绘品牌字标（餐饮门店·轻松拍） |
| Title 1 | 28 / 34 | 56 | 700 | 页面级标题（我的创作） |
| Title 2 | 22 / 28 | 44 | 650 | 区块标题（分镜脚本） |
| Headline | 17 / 22 | 34 | 650 | 卡片标题（菜品名） |
| Body | 15 / 24 | 30 | 400 | 正文、文案内容 |
| Subhead | 13 / 20 | 26 | 400 | 副信息、说明 |
| Caption | 11.5 / 16 | 23 | 550 | 标签、积分提示 |

数字一律用 `font-variant-numeric: tabular-nums` + 负字距，保证金额/积分对齐。

## 4. 圆角、间距、阴影

- **圆角**：标签 12rpx(6px) · 按钮/输入框 20rpx(10px) · 卡片 36rpx(18px) · 弹层 48rpx(24px) · 胶囊 999px
- **间距基数**：8rpx，常用 16 / 24 / 32 / 48rpx；页面左右安全边距 **36rpx(18px)**
- **阴影**：卡片 `0 2rpx 6rpx rgba(17,17,20,.04), 0 16rpx 48rpx rgba(17,17,20,.05)`；主按钮 `0 12rpx 36rpx rgba(225,37,27,.22)`
- 层次靠「留白 + 灰阶」建立，**禁止渐变、光晕、重投影**

## 5. 核心组件

### 按钮层级（一屏最多一个红色实心）

| 类型 | 样式 | 用途 |
| --- | --- | --- |
| Primary | `#E1251B` 底 + 白字 + 红晕 | 首页开始创作、生成成片（按页面只保留一个） |
| Secondary | `#FDECEA` 底 + 红字 | 重新生成、订阅 |
| Ghost | 白底 + `#EDEEF0` 描边 | 复制、编辑 |
| Gray | `#F2F3F5` 底 | 取消、次要操作 |
| Disabled | `#F2F3F5` 底 + `#BFC3C9` 字 | 未满足前置条件 |

高度：常规 96rpx · 底部操作条内 104rpx · 小按钮 72rpx。

### 状态标签

文案款式（流量/介绍/质量）用浅红底红字；镜头复杂度用灰底；任务状态按语义：已完成绿、进行中金、失败红。

### 分段控件（取代原生 Picker）

文案款式、镜头复杂度、订阅/加油包统一使用 iOS 分段控件：灰底容器 + 白色选中块 + `--sh-1` 微投影。**选中即生效**，不需确认。

### 输入框

默认 `#F2F3F5` 填充、无边框；聚焦变白底 + 1.5px 红色描边 + `0 0 0 3.5px rgba(225,37,27,.16)` 光环。

### 进度反馈

统一「红色细进度条 + 百分比 + 文案」。禁止无反馈的转圈。

### 优秀作品卡（首页两列网格 + 上拉加载）

**布局：一行两个、纵向排布**，不走横向滑动（横滑一次只能看一个半，纵向刷更符合"刷视频"的习惯）。

| 要素 | 规格 |
| --- | --- |
| 网格 | `flex-wrap` 两列，列间距 20rpx，行间距 20rpx；单列宽 `calc(50% - 10rpx)` = 329rpx |
| 卡片 | 高 585rpx（竖版 9:16），圆角 20rpx |
| 封面 | 后台真实 `coverUrl` 优先；无图时按作品分类回退到本地 AI 商业摄影 JPG，只有分类也无兜底时才显示「封面待补」 |
| 标签 | 左上，20rpx 白字 + `rgba(0,0,0,.42)` 底 + 背景模糊，胶囊，可换行 |
| 播放 | 正中 80rpx 白色圆底（92% 不透度）+ CSS 三角（不用图标字体），**不是**红色 |
| 标题 | 左下，26rpx / 650 / 白色 + 文字投影，最多 2 行省略 |
| CTA | 标题下方 52rpx 红色胶囊「生成同款」，带 `--ds-glow-red` 红晕 |
| 分类 | 网格上方一行横滑 pills：灰底默认 / **红底选中**，选中即生效并重置分页 |
| 空态 | 整行宽、240rpx 高虚线灰底块，文案「「XX」暂无推荐作品」 |

**分页（上拉加载更多）**

| 状态 | 表现 |
| --- | --- |
| 还有更多 | 底部 88rpx 高提示「上拉或点击加载更多」（红色文字，可点） |
| 加载中 | 「正在加载…」（灰字），期间不重复触发 |
| 已全部加载 | 「已经到底了 · 共 N 个作品」（灰字） |

每页 6 条（3 行）；页面配置 `onReachBottomDistance: 120`；切换分类时重置回第一页。

**红色用量约束**：卡片 CTA 是 52rpx 小规格胶囊，视觉权重明显低于 96rpx 全宽主按钮；且该区块位于首屏之外，下滑后才与「新建创作」同屏——不构成两个主行动竞争。分类 pill 的选中态用红，属于「当前选中态」这一红色合法用法。

## 7. 交互与可用性约束

| 场景 | 规范 |
| --- | --- |
| 触控尺寸 | 可点击元素 ≥ 88rpx × 88rpx（44pt）；相邻可点区域间距 ≥ 16rpx |
| 拇指热区 | 主行动固定在底部操作条；顶部只放导航与门店切换 |
| 点击反馈 | 实心红 → `#C21B12`；卡片 → `scale(.98)` + 透明度 .7，120ms；禁用系统灰色遮罩 |
| AI 等待 | 按钮 loading 并锁定防重复提交；超 8 秒追加「AI 正在写，通常 5–15 秒」 |
| 上传进度 | 选完视频立刻显示本地缩略图占位，不等上传完成；失败保留卡片并给「重新拍摄」 |
| 消耗告知 | 扣费按钮旁常驻积分预估；提交前底部弹层二次确认，写明「按实际时长结算，失败全额返还」 |
| 空状态 | 不用「暂无数据」，改为「还没有门店 → 去创建」这类带下一步动作的文案 |
| 错误处理 | 用页面内联提示条（浅红底）而非 Toast；每条错误必须带可点击的恢复动作 |
| 门店上下文 | 门店切换器常驻首页/创作/菜品/人设页左上角，切换后当前页立即重载 |
| 动效 | 只用 `ease-out`，200–260ms；仅用于转场、弹层升起、进度推进 |
| 对比度 | 正文 ≥ 7:1；次要文字 ≥ 4.5:1 |

### 优秀作品数据与封面策略

优秀作品已接入独立运营内容接口 `GET /api/v1/works`，支持分类、分页和总数；作品详情与「生成同款」配方均来自后端，不依赖商家创作记录。
封面采用三级策略：后台真实 `coverUrl` → 分类 AI 商业摄影 JPG（餐饮/教培/美业/生活服务/休闲娱乐）→「封面待补」。卡片只有存在 `videoKey` 时显示播放按钮，避免把静态封面误导为可播放视频。

### 产品职责与创作阶段

- **首页**：启动今日创作、承接最近项目、浏览优秀作品；不再展示积分，也不重复门店、菜品、人设管理入口。
- **创作项目库**：负责项目推进，通过 `copyText` 与分镜数量推断进行中/已就绪。
- **门店 / 菜品 / 人设**：分别承担品牌资料、菜品内容资产和品牌声音配置。
- **我的**：只负责账户、订阅和积分权益。
- **四步创作**：文案 → 分镜 → 素材 → 成片。新建页先说明创作目标；已建项目、拍摄页、合成页分别显示 `STEP n OF 4` 阶段任务。
- **拍摄上传**：每个分镜独立显示上传状态和进度，允许多个分镜并发上传；已上传素材自动保存，也允许部分素材继续进入合成。

### 两处有意偏差（与初版设计稿不同）

- **创作列表的筛选**：稿子是「全部 / 进行中 / 已完成」，实际改为「**全部 / 进行中 / 已就绪**」。
  原因：后端 `Creation.status` 目前恒为 `DRAFT`、从不写入，拿不到真实状态；改为用列表里确定存在的字段判定——`copyText` 有值算 50%、有分镜算 50%，两者齐备即「已就绪」。
- **合成成片的 AI 档**：稿子里置灰标「能力验收中」，实际代码里 AI 档已开放（AI 配音 + 字幕，系数 1.5×），因此**三档都可选**，没有置灰。

### 后续可做（非阻塞）
