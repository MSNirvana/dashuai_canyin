## 2. 创作主流程（含豆校验点）

```
登录（手机号 + 验证码，勾选协议）
  └─ 注册：自动建默认门店 + 发放注册赠豆 30
        ↓
home（选/切门店）　　※ 豆余额常驻顶部
  ↓  新建创作
creation：选门店 → 选菜品 → 选赛道 → 选复杂度
  ↓  【校验点 ①】余额 ≥ 5 豆？
  ↓  否 → 弹充值（展示会员折扣对比）→ 充值后自动继续
AI 文案生成 → 冻结 → 调 AI → 成功扣 5 豆 / 失败全额退还 + 兜底模板
  ↓  可编辑、可复制、重新生成（同样 5 豆）
  ↓  【校验点 ②】余额 ≥ 10 豆？
AI 分镜生成 → 2-3 镜（简单）/ 5-6 镜（复杂）
  ↓
shoot：按槽位拍摄上传（直传 COS，分片续传）
  · 每槽位：拍摄要点（AI 生成） + 示范视频（未配置显示占位）
  · 首帧拼图预览（0 豆，随时可看）
  ↓
render：调色（亮度 / 对比度 / 饱和度 / 色温，整片统一）
  ↓  【校验点 ③】余额 ≥ 30 豆（命中缓存则 10 豆）？
提交合成 → FFmpeg 队列 → 进度轮询 2s → 完成通知
  ↓  失败/超时 → 全额退豆，可重试
成片：预览 → 保存到相册（失败降级下载链接）→ 可反复下载（不重复扣豆）
```

## 3. 关键状态机

**creation**：`DRAFT → COPIED → STORYBOARDED → SHOTS_UPLOADED → RENDERING → DONE`

**render_task**：`QUEUED → RUNNING → SUCCESS / FAILED / TIMEOUT / CANCELLED`
- 失败自动重试 1 次；超时阈值 `task_timeout_minutes`
- 同一 creation 存在 RUNNING/QUEUED 任务时禁止重复提交（4001）
- **失败/超时必须全额退豆**，退豆与状态更新在同一事务

**order**：`PENDING → PAID / FAILED / CLOSED / REFUNDED`
- PENDING 超 30 分钟自动 CLOSED
- 支付回调以 `wx_transaction_id` 幂等

**bean_ledger 流转**
```
RECHARGE（充值）  GRANT（会员赠送）
FREEZE（执行前冻结） → CONSUME（成功扣减）+ UNFREEZE（差额解冻）
                    → UNFREEZE（失败全额解冻）
EXPIRE（赠豆到期清零）  REFUND  ADJUST（后台调账）
```

## 4. 豆校验点汇总

| # | 位置 | 需豆 | 不足时 |
|---|---|---|---|
| ① | 生成 / 重新生成文案 | 5 | 弹充值，充值后自动继续 |
| ② | 生成 / 重新生成分镜 | 10 | 同上 |
| ③ | 提交合成 | 30（缓存命中 10） | 同上 |

**统一错误码** `2001 BEAN_NOT_ENOUGH`，响应带 `required` 与 `balance` 字段，前端直接渲染弹窗文案。

> 权限中间件已取消：全应用**不再有会员权限校验**，只剩余额校验。

## 7. 上线前必查项

- [ ] **支付回调幂等**：模拟重复通知，确认不重复发豆 / 不重复开通会员
- [ ] **AI 生成幂等**：同一 requestId 连点 5 次，只扣一次豆
- [ ] **并发扣豆**：并发 20 请求，余额不为负
- [ ] **退豆正确性**：AI 超时、合成失败、合成超时三种场景均全额退还
- [ ] **通道故障转移**：主通道 key 置错，确认自动切备用；全部置错，确认返回兜底且不扣豆
- [ ] **重合成计费**：仅改调色命中缓存扣 10 豆；换素材扣 30 豆
- [ ] 2GB 文件上传（弱网中断后续传）
- [ ] 合成超时与重试（人为 kill ffmpeg，确认状态与退豆正确）
- [ ] 隐私政策与用户协议在小程序的可见入口
- [ ] 类目与资质审核已通过
