## 4. 当前已完成的关键改动

### 认证
- access/refresh/admin token 类型隔离
- issuer / audience / HS256 校验
- 商家 ACTIVE 状态检查
- refresh 失败后清理会话并跳回登录页
- 登录/refresh 返回 `available/frozen` 快照

### 支付
- 支付 raw body 先于 JSON parser
- snake_case 映射
- 商户号/金额/CNY/时间窗校验
- 缺配置时生产不自动发权益
- 仅非生产显式 `PAYMENT_MODE=test` 允许演示支付

### 订单与充值
- `/orders/me` 不再被 `/:orderNo` 遮蔽
- 前端充值只在服务端 `PAID` 后刷新账户并提示到账
- 取消/支付失败不进入确认态

### 门店/菜品
- 门店城市、区县下拉选择
- 菜品支持图片、视频上传
- 菜品新增 `video_key` 字段
