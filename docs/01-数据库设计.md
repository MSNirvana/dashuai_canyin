# 详细设计 01 · 数据库设计

> 项目：大帅餐饮短视频创作工具　|　版本：v1.0　|　数据库：MySQL 8.0 / InnoDB
> 配套：《架构方案要点 定稿 v3》

---

## 0. 全局约定

| 约定 | 规则 |
|---|---|
| 字符集 | `utf8mb4` / `utf8mb4_0900_ai_ci` |
| 主键 | `BIGINT UNSIGNED AUTO_INCREMENT` |
| 时间 | `DATETIME(3)`，全部存 **UTC**，应用层转本地 |
| 金额 | 一律用**分**（`INT UNSIGNED`），禁止浮点 |
| AI 价格 | 用「**分 / 百万 tokens**」整数存储，禁止浮点 |
| 删除 | 业务数据一律**软删除** `deleted_at DATETIME(3) NULL` |
| 乐观锁 | 账务类表必带 `version INT NOT NULL DEFAULT 0` |
| 枚举 | 用 `VARCHAR` + 应用层校验，便于后台扩展；关键枚举加 CHECK |
| 外键 | 不建物理外键，靠应用层 + 索引保证（便于分库与迁移） |

```
merchant ─1:N─ store ─1:N─ dish
```

## 2. 商家与门店

```sql
CREATE TABLE merchant (
```


## 4. AI豆账务

```sql
CREATE TABLE bean_account (
  id              BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  merchant_id     BIGINT UNSIGNED NOT NULL,
  balance         BIGINT NOT NULL DEFAULT 0 COMMENT '充值豆可用余额',
  grant_balance   BIGINT NOT NULL DEFAULT 0 COMMENT '赠豆可用余额（优先消耗，会员到期清零）',
  frozen          BIGINT NOT NULL DEFAULT 0 COMMENT '冻结中（含充值豆+赠豆，明细见 ledger）',
  total_recharge  BIGINT NOT NULL DEFAULT 0,
  total_grant     BIGINT NOT NULL DEFAULT 0,
  total_consume   BIGINT NOT NULL DEFAULT 0,
  version         INT NOT NULL DEFAULT 0 COMMENT '乐观锁',
  updated_at      DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
  PRIMARY KEY (id),
  UNIQUE KEY uk_merchant (merchant_id)
) ENGINE=InnoDB COMMENT='AI豆账户';

CREATE TABLE bean_ledger (
  id             BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  merchant_id    BIGINT UNSIGNED NOT NULL,
  type           VARCHAR(24) NOT NULL COMMENT 'RECHARGE/GRANT/FREEZE/UNFREEZE/CONSUME/REFUND/EXPIRE/ADJUST',
  bucket         VARCHAR(16) NOT NULL DEFAULT 'RECHARGE' COMMENT 'RECHARGE充值豆/GRANT赠豆',
  amount         BIGINT NOT NULL COMMENT '正数=增加可用，负数=减少可用',
  balance_after  BIGINT NOT NULL,
  grant_after    BIGINT NOT NULL DEFAULT 0,
  frozen_after   BIGINT NOT NULL DEFAULT 0,
  biz_type       VARCHAR(32) DEFAULT NULL COMMENT 'AI_COPY/AI_STORYBOARD/ORDER/ADMIN/MEMBER_EXPIRE',
  biz_id         VARCHAR(64) DEFAULT NULL,
  request_id     VARCHAR(64) DEFAULT NULL COMMENT '幂等键',
  remark         VARCHAR(255) DEFAULT NULL,
  operator_id    BIGINT UNSIGNED DEFAULT NULL COMMENT '后台手动调账操作人',
  created_at     DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  PRIMARY KEY (id),
  UNIQUE KEY uk_request_type (request_id, type),
  KEY idx_merchant_time (merchant_id, created_at),
  KEY idx_biz (biz_type, biz_id)
) ENGINE=InnoDB COMMENT='AI豆流水（幂等核心）';

CREATE TABLE bean_package (
  id              BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  name            VARCHAR(128) NOT NULL,
  beans           BIGINT NOT NULL COMMENT '基础豆数',
  bonus_beans     BIGINT NOT NULL DEFAULT 0 COMMENT '赠送豆数',
  price_fen       INT UNSIGNED NOT NULL COMMENT '原价（分）',
  member_price_fen INT UNSIGNED NOT NULL COMMENT '会员价（分）',
  tag             VARCHAR(32) DEFAULT NULL COMMENT '角标：热卖/超值',
  sort            INT NOT NULL DEFAULT 0,
  enabled         TINYINT(1) NOT NULL DEFAULT 1,
  created_at      DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  updated_at      DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
  PRIMARY KEY (id),
  KEY idx_enabled (enabled, sort)
) ENGINE=InnoDB COMMENT='AI豆充值档位（后台可配置）';
```

> **幂等实现说明**：`uk_request` 为唯一索引。同一 `request_id` 第二次插入会抛 duplicate key，应用层捕获后直接返回首次结果，**绝不重复扣豆**。
> **原子扣减说明**：必须单条 `UPDATE ... WHERE balance >= :amt AND version = :version`，禁止先 SELECT 后 UPDATE。

## 8. 初始化配置数据（`system_setting` 种子）

| group_key | setting_key | 默认值 | 说明 |
|---|---|---|---|
| store | max_stores_free | 1 | 非会员门店数上限 |
| store | max_stores_member | 10 | 会员门店数上限 |
| bean | beans_per_yuan | 100 | 1 元 = 100 豆 |
| bean | register_grant_beans | 30 | 新用户注册赠豆 |
| bean | member_discount_rate | 0.80 | 会员购豆折扣 |
| bean | charge_mode | FLAT | `FLAT`=按标价扣；`COST_BASED`=按成本×系数扣（不超标价） |
| bean | cost_multiplier | 4.0 | 实际成本 × 系数（毛利监控用，不直接向用户计费） |
| render | ffmpeg_concurrency | 3 | 转码并发数 |
| render | task_timeout_minutes | 30 | 单任务超时 |
| render | max_total_duration_sec | 180 | 成片最大时长 |
| render | free_preview_enabled | 0 | 非会员是否有首帧拼图预览（建议 1） |
| upload | max_file_size_mb | 2048 | 单文件上限 |
| upload | recommend_size_mb | 500 | 建议大小 |
| ai | circuit_fail_threshold | 0.5 | 熔断失败率阈值 |
| ai | circuit_window_size | 20 | 熔断滑动窗口 |
| ai | circuit_open_seconds | 60 | 熔断时长 |

> **边界说明**：服务器 CPU/内存规格属于硬件采购，无法在后台修改；后台可调的是"用多少资源"（并发数、超时、单任务上限）。建议采购 **8 核 16G**，届时把 `ffmpeg_concurrency` 调到 3–4。
