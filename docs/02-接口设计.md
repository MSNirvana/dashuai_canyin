# 详细设计 02 · 接口设计

> 项目：大帅餐饮短视频创作工具　|　版本：v1.0　|　风格：REST / JSON

---

## 1. 通用约定

**Base URL**：`https://{已备案域名}/api/v1`（后台管理为 `/admin/api/v1`）

**鉴权**：`Authorization: Bearer <access_token>`（JWT，access 2h / refresh 30d）。
小程序端启动携带 `X-Platform: WEAPP | DOUYIN`、`X-Version`、`X-Store-Id`（当前门店）。

**统一响应**

```json
{ "code": 0, "message": "ok", "data": {}, "traceId": "..." }
```

**错误码**

| code | 含义 | 前端处理 |
|---|---|---|
| 0 | 成功 | — |
| 1001 | 未登录 / token 失效 | 跳登录页 |
| 1002 | 短信验证码错误或过期 | 原地提示 |
| 1003 | 短信发送过于频繁 | 倒计时提示 |
| 2001 | **AI豆余额不足** | 弹充值引导 |
| 2002 | **非会员，无权限** | 弹会员订阅引导 |
| 2003 | 门店数量已达上限 | 提示升级会员 |
| 3001 | 文件超出大小限制 | 提示压缩/裁剪 |
| 3002 | 素材不存在或未就绪 | 重新上传 |
| 4001 | 合成任务进行中，勿重复提交 | 跳进度页 |
| 4002 | 合成失败 | 展示错误 + 重试按钮 |
| 5001 | AI 服务暂时不可用（已降级） | 展示兜底内容 + 稍后再试 |
| 9001 | 幂等命中，返回首次结果 | 静默使用返回结果 |

**幂等**：所有写操作（尤其 AI 生成、下单、支付回调）必须支持幂等键。
- AI 生成：请求体带 `requestId`（前端 UUID）
- 下单：请求体带 `requestId`
- 支付回调：以 `wx_transaction_id` 幂等

## 2. 认证

### `POST /auth/wechat-login`　**默认入口**，微信一键授权
```json
// req
{ "phoneCode": "getPhoneNumber 返回的 code", "wxLoginCode": "wx.login() 返回的 code" }
// res
{ "data": { "token": "...", "refreshToken": "...",
    "merchant": { "id": "1", "phone": "189****2152", "isNew": true },
    "member": { "isMember": false, "endAt": null },
    "bean": { "balance": "0", "grantBalance": "30" }
}}
```
- 需要小程序已申请「手机号快速验证」（按次付费 ¥0.04/次）
- `wxLoginCode` 用于 code2session 拿 openid，仅做账号关联与审计
- `phoneCode` 用于 verifysession 拿真实手机号（按次扣费）
- 按手机号匹配账号；首次绑定 openid；同手机号换微信号会自动重新绑定
- 新用户自动建默认门店 + 发放注册赠豆

### `POST /auth/sms/send`　**辅助入口前置**
```json
// req
{ "phone": "189****2152", "scene": "LOGIN" }
// res
{ "data": { "cooldownSec": 60 } }
```
- 同号码 60s 一次、同号码每日 10 次、同 IP 每日 50 次
- 验证码 5 分钟有效，错误 5 次作废

### `POST /auth/login`　**辅助入口**，手机号 + 验证码（兜底通道）
```json
// req
{ "phone": "189****2152", "code": "123456" }
// res：与 /auth/wechat-login 同
{ "data": { "token": "...", "refreshToken": "...", "merchant": {...}, "member": {...}, "bean": {...} }}
```
- 校验通过后按手机号匹配账号（无 openid 关联）
- 用于拒接授权 / 网络问题 / 微信未登录场景

### `POST /auth/refresh`　刷新 access token
```json
// req
{ "refreshToken": "..." }
// res：与 /auth/wechat-login 同
```

**未登录统一错误码 `1001`**；短信相关 `1002`（码错）/`1003`（频次过高）；微信一键失败 `1004`。

## 4. 素材上传（直传 COS）

### `POST /media/presign`
```json
// req
{ "storeId": 1, "type": "VIDEO", "filename": "a.mp4", "sizeBytes": 314572800, "mimeType": "video/mp4" }
// res
{ "data": {
    "assetId": 1001,
    "upload": { "method": "POST", "url": "https://...", "formData": { "key": "...", "policy": "...", "signature": "..." } },
    "chunk": { "enabled": true, "chunkSize": 5242880 },
    "maxSizeMb": 2048, "recommendSizeMb": 500
}}
```
- 服务端生成 `assetId` 与 COS key，**前端直传，不经过应用服务器**
- 超过 `max_file_size_mb` 返回 3001

### `POST /media/callback`
```json
// req
{ "assetId": 1001 }
// res
{ "data": { "assetId": 1001, "status": "READY", "durationMs": 12000, "width": 1080, "height": 1920, "coverUrl": "..." } }
```
- 服务端 ffprobe 探测元数据 + 抽首帧；失败置 `FAILED`

## 5. AI 生成（核心：先冻后扣 + 幂等）

### `POST /ai/copy`　生成口播文案
### `POST /ai/storyboard`　生成分镜脚本

```json
// req（copy）
{ "requestId": "uuid-xxx", "creationId": 101, "storeId": 1, "dishId": 5,
  "track": "TRAFFIC", "complexity": "SIMPLE", "regenerate": false }

// req（storyboard）
{ "requestId": "uuid-xxx", "creationId": 101, "copyText": "（可编辑后的文案）", "complexity": "COMPLEX" }

// res
{ "code": 0, "data": {
    "text": "生成的文案内容...",
    "beanCharged": 5, "beanBucket": "GRANT",
    "balance": { "balance": 995, "grantBalance": 25 },
    "usedFallback": false,
    "isFallbackTemplate": false,
    "traceId": "..."
}}
```

**服务端时序（必须严格按此实现）**

1. 校验 `requestId` 是否已存在 → 命中则直接返回首次结果（`code=9001`）
2. 查询 `ai_scene` 取标价 `bean_price` → 冻结金额 `freeze = ceil(bean_price × freeze_buffer_rate)`
3. 校验可用余额（赠豆优先）≥ 标价 → 不足返回 2001
4. 事务内冻结：写 `bean_ledger(type=FREEZE)` + 更新 `bean_account.frozen`
5. 调 AI 网关（含故障转移，见 03 文档）
6. **成功**：`charged = min(freeze, ceil(实际成本 × cost_multiplier))`，扣减 + 解冻差额，写 `CONSUME` + `UNFREEZE` 两条流水 + `ai_call_log`
7. **失败/超时**：全额解冻，写 `UNFREEZE`，返回 5001 + 兜底模板文案（`isFallbackTemplate=true`，**不扣豆**）
8. 全程同一事务写 ledger 与 account，`version` 乐观锁校验

**并发安全**
```sql
UPDATE bean_account
   SET balance = balance - :amt, frozen = frozen + :amt, version = version + 1
 WHERE merchant_id = :mid AND balance >= :amt AND version = :ver;
```
影响行数为 0 → 重试 3 次 → 仍失败返回 2001。

## 6. 粗剪合成

### `POST /render`
```json
// req
{ "creationId": 101, "params": { "brightness": 0, "contrast": 1.0, "saturation": 1.0, "temperature": 6500 },
  "shots": [ { "shotId": 11, "assetId": 1001, "trimStartMs": 0, "trimEndMs": 8000 } ] }
// res
{ "data": { "taskId": 9001, "status": "QUEUED", "queuePosition": 2, "estimateSec": 240 } }
```

**权限**：**必须会员**。非会员直接返回 `2002`，前端弹订阅引导，不创建任务。
（免费首帧拼图预览由 `/render/preview-collage` 提供，非会员可用）

### `GET /render/:taskId`
```json
{ "data": { "taskId": 9001, "status": "RUNNING", "progress": 45,
            "estimateRemainSec": 120, "resultUrl": null, "errorMsg": null }}
```
- 前端 2s 轮询；完成后用订阅消息兜底通知

### `POST /render/preview-collage`
零成本预览：抽取各片段首帧，按脚本顺序拼一张图返回。**不跑转码**，非会员可用。

### `GET /render/:taskId/download`
返回 COS 签名下载 URL（有效期 15 分钟）；保存相册失败时降级为此链接。

## 8. 会员与订单

| Method | Path | 说明 |
|---|---|---|
| GET | `/member/packages` | 会员套餐（含 grantBeans、权益说明） |
| GET | `/membership/current` | 当前会员状态、到期时间、剩余赠豆 |

### `POST /order/create`
```json
// req
{ "requestId": "uuid-xxx", "orderType": "RECHARGE_BEAN", "refId": 3 }
// 或 { "orderType": "MEMBERSHIP", "refId": 2 }
// res
{ "data": { "orderNo": "...", "amountFen": 8000, "originalAmountFen": 10000,
            "payParams": { "timeStamp": "...", "nonceStr": "...", "package": "prepay_id=...", "signType": "RSA", "paySign": "..." } }}
```
- `RECHARGE_BEAN` 时按当前会员身份取 `memberPriceFen`
- 订单 30 分钟未支付自动关闭

### `POST /order/notify`（微信支付回调，无需鉴权）
1. 验签（微信支付平台证书）
2. 以 `wx_transaction_id` 幂等：已处理直接返回 SUCCESS
3. 事务内：订单置 PAID → 按类型履约
   - `RECHARGE_BEAN`：充值豆入账（`RECHARGE` 流水）
   - `MEMBERSHIP`：写入/续期 `membership` + 发放赠豆（`GRANT` 流水，`grant_expire_at = end_at`）
4. 返回 `<xml><return_code>SUCCESS</return_code></xml>`

> 微信回调会重复通知，步骤 2 是硬性要求，否则重复发豆 / 重复开通会员。
