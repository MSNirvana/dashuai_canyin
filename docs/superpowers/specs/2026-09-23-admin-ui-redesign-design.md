# 大帅餐饮后台 UI 重设计说明

## 目标

在不改变现有路由、菜单文案、业务接口和页面功能的前提下，重做后台的视觉语言与布局层级。后台面向高频处理商家、内容、合成任务和 AI 通道的运营人员，优先保证扫描效率、状态识别和桌面端空间利用率。

## Design Read

现有餐饮运营后台的整体 redesign，面向运营人员，采用克制的红白工作台语言，保留 TDesign 和数据表能力，去掉渐变、重阴影和 AI 炫技装饰。

设计参数：`DESIGN_VARIANCE 4`、`MOTION_INTENSITY 2`、`VISUAL_DENSITY 7`。

## 保留边界

- 保留现有 React、React Router、TDesign 和权限上下文。
- 保留全部路由、菜单文案、接口调用、表单字段名、表格数据和操作行为。
- 保留告警角标、告警跳转、懒加载和错误边界。
- 不新增虚构统计数据、装饰性图表或营销文案。

## 外壳布局

- 左侧导航宽度约 232px，按“运营 / 交易与任务 / 内容与 AI / 页面与系统”分组。
- 顶部品牌区、菜单区、底部管理员区使用冷白与浅灰层级，当前菜单使用品牌红左边线和浅红背景。
- 主内容区使用固定 64px 顶栏，页面区域独立滚动，避免宽表格把整个窗口推出横向滚动。
- 页面统一采用“页标题与说明 / 筛选与操作 / 数据区 / 状态反馈”的顺序。
- 1024px 以下收窄导航；768px 以下优先保证表格横向滚动与主要操作可见。

## 视觉令牌

- 品牌红：`#c92a21`，只用于选中态、主按钮、进度与危险状态。
- 页面底：`#f5f6f8`；内容面：`#ffffff`；边界线：`#e5e7eb`。
- 标题：`#171717`；正文：`#3f3f46`；辅助信息：`#71717a`。
- 统一 10px 小圆角；取消大面积渐变、玻璃质感、重阴影和发光效果。
- 阴影只保留轻量层级阴影，主要依靠留白、线条和灰阶组织界面。

## 页面重点

- 登录页改为红白分栏：左侧品牌与工作台定位，右侧登录表单；保持默认账号提示和错误反馈。
- 仪表盘改为关键数字、待处理提醒和业务区块的运营首页，统计全部来自原有接口。
- 所有页面通过全局样式统一页头、表格、筛选控件、按钮、标签、弹窗、表单和空状态。
- 不重写业务页面组件，避免本次纯视觉改造影响接口和数据逻辑。

## 验收

- `npm run typecheck` 通过。
- `npm run build` 通过。
- 登录、仪表盘和至少一个数据表路由可正常加载。
- 1024px、1440px 宽度下无外壳横向溢出；宽表格仅内容区滚动。
- 红色只作为单一品牌强调色；无 AI 紫色渐变、装饰性光晕和无意义动画。
