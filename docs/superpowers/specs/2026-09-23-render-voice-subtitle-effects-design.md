# 配音、独立字幕与剪辑效果设计

## 目标

让 AI 成片的配音、字幕和剪辑效果成为三个独立可选能力：用户可以选择服务器音色、上传自己的配音；即使不生成旁白，也能从原视频语音识别字幕；节奏、转场和音频处理选项必须在本地自动剪辑引擎中真实生效。

## 方案

### 配音

- 继续使用服务器配置的 TTS 供应商，并暴露多个可选音色。
- 新增 `CUSTOM` 配音模式。小程序把用户选择的音频文件上传为 `AUDIO` 媒体资产，渲染任务只保存对象键和时长，不保存音频内容。
- 自定义配音优先级高于 TTS；TTS 未配置时保留视频原声，不生成静音冒充配音。
- 音频通过 `apad`/`-shortest` 与成片时长对齐，避免自定义录音过长或过短破坏视频。

### 字幕

- 新增字幕模式：`OFF`、`SOURCE_AUDIO`、`VOICE_AND_SOURCE`。
- `SOURCE_AUDIO` 从归一化后的原视频音轨提取并调用可配置的 OpenAI-compatible Whisper 转写服务。
- `VOICE_AND_SOURCE` 同时转写自定义/TTS旁白和原视频音轨，按时间轴合并，旁白优先避免重复字幕。
- ASR 不可用时，若分镜有文案则回退到文案字幕；没有文案则只保留原声并写入任务警告。
- 字幕样式继续复用现有三档样式；本地引擎使用 FFmpeg/libass 烧录。

### 剪辑效果

- 节奏：`NATURAL`、`FAST`、`STORY`，通过镜头时长系数和台词下界共同约束。
- 转场：`CLEAN` 硬切、`SMOOTH` 交叉淡化、`DYNAMIC` 快速闪白/淡入淡出；素材不足时自动退回硬切。
- 音频：`normalizeAudio` 控制响度归一；`removeSilence` 对口播音频做安全的静音压缩，最大加速不超过 1.35 倍。
- 调色仍由现有颜色参数控制，和效果选项独立。

## 数据流

小程序选择参数 → 上传自定义音频（可选）→ `RenderTask.paramsJson` 保存 voice/subtitle/effect 快照 → Worker 下载素材 → 自动规划 → ASR/TTS → 转场/音频处理 → 字幕烧录 → 输出质检 → COS 上传与积分结算。

## 配置

- `ASR_API_URL`、`ASR_API_KEY`、`ASR_MODEL`：OpenAI-compatible 音频转写接口；未配置时字幕按降级规则处理。
- `CHATCUT_TTS_VOICE_*`：多音色映射；未配置某个映射时使用 TTS 供应商默认音色。

## 验证

- 纯函数测试覆盖字幕模式、效果参数和降级逻辑。
- FFmpeg 冒烟覆盖无旁白原声、字幕烧录和转场输出。
- 小程序类型检查、微信构建和远程 API 健康检查必须通过。
